PROJETO: Desenvolvimento de uma landing page para Makar Contabilidade

DESCRIÇÃO: página comercial desenvolvida durante o curso FULL STACK da Mais Pra TI. O objetivo da página é divulgar comercialmete o escritório de contabilidade ajudando a atrair mais clientes e a fortalecer a marca. Visa atingir clientes pessoa jurídica de todos os portes que necessitem de uma consultoria contábil especializada.

TECNOLOGIAS: utilização de HTML, CSS e javascript puro (Vanilla JS) sem utilização de qualquer biblioteca ou framework. Foram utilizados recursos da plataforma Web3forms, para administração do envio de emails, pois a página não possui backend. Não possui banco de dados.

INICIALIZAÇÃO: executar a página index.html
